# گزارش فنی و برنامه ارتقای کامل ZAVI ONE و ZAVI ONE ADMIN
**تاریخ:** ۲۸ اکتوبر ۲۰۲۶  
**نسخه قابل دریافت QA:** ZAVI ONE 65.98 / ADMIN 1.4.44  
**وضعیت:** پیش‌نشر آزمایشی، نه گواهی پایان تمام درخواست‌ها.

## ۱. شناسایی فناوری از پروژه واقعی
- رابط کاربر و مدیریت: HTML، CSS و JavaScript با اسکریپت‌های خود برنامه و فایل‌های افزایشی طراحی؛ نه ادعای بازنویسی به React.
- Android: Java + Android WebView AssetLoader + Gradle / SDK 36؛ رابط فایل‌های محلی HTML را اجرا می‌کند. گفتار از SpeechRecognizer بومی اندروید و مرورگرها از Web Speech API در صورت پشتیبانی استفاده می‌کند.
- Windows: بسته مستقل Electron x64 و نصب‌کننده Windows که از **همان بسته تأییدشده وب** داخل APK استخراج می‌شود.
- پایگاه داده و ابر: Supabase/PostgreSQL/RLS/RPC موجود. هیچ طرح تغییر DDL یا داده تولیدی در این مرحله به سرور اعمال نشده است.
- Offline/PWA: سرویس‌ورکر، مجوز دستگاه و همگام‌سازی اصلی قبلی. کد تازه برای بازنویسی دفتر حسابداری یا مهاجرت غیرمجاز offline نوشته نشده.
- مخزن: github.com/zavyanmasoom6-glitch/Zavione؛ منبع قابل پیگیری در شاخه zavi-v6598-admin1444-handsfree-easy-voice-qa.

## ۲. فهرست امکانات موجود قابل ردیابی در کد/بسته‌های پیشین
این «فهرست شناخته‌شده و قابل ردیابی» است، **نه ادعای خواندن تک‌تک خط‌های کد بسته‌بندی‌شده یا تأیید صددرصد دستی هر صفحه**:
۱. پروفایل‌های جداگانه ۲۰ صنف، مدیریت روزمره تخصصی، فروش و خرید و فاکتورهای اصلی.
۲. انبار/گدام و موجودی، بارکد و دوربین و دیکودر ZXing داخلی.
۳. مشتریان، قرضداران، حساب‌های نقدی و گزارش‌ها و چاپ فاکتور/رسید.
۴. داشبورد، گزارش/نمودار، نرخ دالر دستی، تنظیمات و انتخاب حالت روشن/تیره.
۵. ورود ابری، نشست و تمدید، ۷ روز امتحانی و مجوز آنلاین/آفلاین دستگاه اصلی.
۶. انتقال دستگاه اصلی و ممانعت‌های معاملات ارسال‌نشده (مبتنی بر مسیر سرور موجود، نیازمند QA واقعی).
۷. همکاران و دسترسی فروش/خرید و پنهان‌سازی اطلاعات سرمایه و سود.
۸. تنظیم جداگانه اندازه متن/سیستم/آیکن (۵۰ تا ۱۵۰ درصد) و چیدمان موبایل/آیپد.
۹. رابط سه‌زبانه موجود که برخی ترجمه‌های آن هنوز ناقص‌اند.
۱۰. دستیار آفلاین قبلی از نوع راهنمای محلی و حسابگر، نه مدل هوش مصنوعی زبانی آفلاین تضمین‌شده.
۱۱. ADMIN خصوصی مالک، فهرست مشتریان، اشتراک/تمدید، پشتیبانی، رسیدها، گزارش مالی، فعالیت و مدیریت وضعیت دستگاه.
۱۲. ADMIN پیام‌های دستی/تبریک/یادآوری واتساپ با رضایت مخاطب و بدون ارسال خودکار؛ برخی سوابق پیام فقط در نشست محلی و سرور migration هنوز نصب نشده.
۱۳. Windows Setup، Android APK، PWA/Web و نام/لوگوی اختصاصی سیستم.

## ۳. چه تغییراتی حقیقتاً در V65.98 / 1.4.44 اجرا و ساخته شده؟
- دکمه کوچک گرد میکروفون در محیط اپ؛ سفید واضح در Light، سرمه‌ای در Dark.
- پنل بسیار ساده و خوانا: فعال/غیرفعال یک‌باره، زبان/لهجه، نشانگر وضعیت و نمونه جمله.
- زبان/لهجه گفتار: دری افغانستان `fa-AF`، فارسی `fa-IR`، پشتو `ps-AF` و انگلیسی `en-US`/`en-GB`. **وجود سرویس/مدل دقیق هر زبان، به‌ویژه پشتو، در دستگاه تضمین نیست.**
- موتور Android SpeechRecognizer با `RECORD_AUDIO` صریح و پل بومی فقط برای Origin داخلی و MainFrame؛ محدود به برنامه در پیش‌زمینه و متوقف‌شدن هنگام خروج/پس‌زمینه.
- گزینه ذخیره‌شده فعال؛ در Android پس از اجازه اولیه هنگام بازشدن برنامه، با حفظ مجوز می‌تواند به شنیدن برگردد؛ به محدودیت سرویس تشخیص، باتری و قطع نشست وابسته است. در وب و Windows شنیدن پیوسته تضمین نمی‌شود.
- تشخیص دستورهای جابه‌جایی بین بخش‌ها، پیش‌نویس فروش/خرید؛ بدون ثبت قطعی صرفاً بر اساس گفتار.
- امکان تصحیح دستور از طریق متن در پنل. حفظ مسیر قدیمی فاکتور برای تأیید و پردازش واقعی.
- تمام ۲۰ پروفایل در manifest اصلی باقی مانده؛ آزمون HTML تضمین می‌کند رشته‌های HTML فاکتور تعبیه‌شده از وسط قطع نشده‌اند.

## ۴. درخواست‌های بزرگ که هنوز تکمیل نشده‌اند
- ترجمه *همۀ* متن‌های ثابت، خطاهای سرور، چاپ‌ها و تمام اسناد به فایل کاتالوگ زبان مرکزی و تغییر بی‌نقص فوری در تمام صفحات.
- تقویم شمسی + میلادی در هر صفحه/فاکتور، اعداد و واحدهای پول متناسب با هر زبان، QA کامل فونت پشتو برای چاپ واقعی.
- انیمیشن حرفه‌ای ۶۰fps و «کاهش انیمیشن» یکپارچه در هر دو اپ؛ وجود فایل‌های سینمایی قبلی به معنی تست هر نما نیست.
- نمودارهای زنده واقعی با اشتراک‌گذاری داده امن، فیلتر روز/هفته/ماه/سال و انیمیشن شمارش.
- **ثبت تراکنش صوتی واقعی**: نیازمند شناسایی کالا از فضای کاری همان فروشگاه، کنترل واحد و قیمت/موجودی/ارز، مجوز همکار، تأیید مستقل و idempotency.
- ثبت امن تاریخچه تمام فرمان‌های صوتی در سرور با tenant isolation و مجوز حذف/نگهداری مشخص.
- مرحله اجباری اتصال ابری برای کاربران جدید و سازوکار مهاجرت امن کاربران فعلی بدون از بین رفتن داده آفلاین؛ نیازمند تست lease و sync و جلوگیری از قفل کردن مشتری قدیمی.
- پشتیبان‌گیری رمزگذاری‌شده/خودکار به همراه **آزمایش بازیابی**؛ فعلاً ادعای فعال‌بودن کامل آن نشده.
- ممیزی کامل امنیت/RLS/حدود ۸۳ RPC با `SECURITY DEFINER`، دستگاه واقعی و تست مالک/همکار/مستأجر.

## ۵. معماری توسعه پیشنهادی بدون تداخل
**فاز A: تثبیت پایه** — فهرست تمام صفحات و رشته‌ها از HTML/JS استخراج و manifest تست regression برای ۲۰ صنف ساخته شود؛ QA آفلاین/بازگشت sync و مجوز مالک.
**فاز B: i18n** — فایل‌های `fa-AF.json`, `ps-AF.json`, `en.json`، رمز هر رشته در کد و Adapter برای خطاهای RPC/فاکتور/چاپ؛ زبان در تنظیمات ذخیره و هنگام تغییر RTL/LTR بلافاصله تغییر کند، dual-calendar با Intl و تبدیل معتبر محلی. چاپ واقعی فونت پشتو بررسی شود.
**فاز C: انیمیشن و نمودار** — حرکت سبک با `transform/opacity`، `prefers-reduced-motion` و toggle، توقف حرکت پشت صفحه؛ گزارش مالی تنها از RPCهای مجاز همان فروشگاه و فیلترهای امن؛ بدون polling بی‌هدف.
**فاز D: صوت تخصصی** — برای ۲۰ صنف واژه‌نامه و parser واحد/IMEI/عیار/ارز متفاوت؛ صدور پیش‌نویس، انتخاب ابهام، تأیید صوتی + تأیید دستی یا احراز هویت لازم برای عملیات مالی، ارسال یکباره به مسیر اصلی و ثبت Audit قابل اطمینان.
**فاز E: ابر/امنیت/بازیابی** — حساب جدید با فعال‌سازی ابری پیش از اولین معامله، ورود آفلاین فقط با مجوز قبلاً صادرشده؛ نصب آزمایشی migration؛ تست خراب‌نشدن داده در همگام‌سازی و انتقال دستگاه؛ backup+restore.

## ۶. تست‌های ضروری قبل از اعلام نسخه نهایی
- حساب‌های مالک ADMIN، فروشنده، همکار خرید، همکار محدود و مهمان نمی‌توانند مجوز دیگری را دور بزنند.
- ۲۰ صنف × ایجاد خرید/فروش، تخفیف، برگشت، چاپ، آفلاین و همگام‌سازی بدون دوبرابرشدن سند.
- Android، iPad Safari، Windows Electron، وب؛ شبکه قطع و وصل؛ دستگاه کوچک/بزرگ؛ چرخش صفحه.
- سه زبان × تمام صفحات، RTL/LTR، تاریخ و ارز و فونت پشتو، A5/رسید حرارتی، متن خطا.
- فرمان صوتی مبهم، عدد فارسی/پشتو، چند جنس، تشخیص ضعیف، میکروفون قطع/رد، خروج به پس‌زمینه، غیرمالک ADMIN.
- پشتیبان‌گیری و بازیابی روی محیط آزمایشی؛ جلوگیری از حذف داده آفلاین؛ نصب نسخه قبلی/جدید.
- CI فعلی: `node design-system/test_voice_v6596.cjs`، `node design-system/test_dashboard_mic_v6597.cjs`، `node design-system/test_easy_handsfree_v6598.cjs`، `python3 design-system/test_html_integrity_v6590.py --web android-build/app/src/main/assets --app one`.
- **موفقیت CI به معنی آزمایش میکروفون و دیتابیس روی موبایل واقعی نیست.**

## ۷. روش ساخت APK و Windows مطابق خود مخزن
نیازمندی‌ها: GitHub Actions (ساده‌ترین)، Java 17، Android SDK API36/Build Tools 36، Gradle 8.x، Python 3، Node، ZXing build vendor.
```bash
# از ریشه مخزن؛ baseline APK دارای SHA ثابت باید در design-staging موجود باشد.
python3 design-system/build_android_v6598.py --app one --apk design-staging/one.apk --expected-sha fee4ae8ec59a8d433f95c631fe26dfd46fcb8d4916aca01ed5b3090cf5a4d018
(cd android-build && gradle --no-daemon -PzaviApp=one :app:assembleRelease)
# برای ADMIN با baseline SHA تاییدشده خودش؛ ساخت را در محیط تمیز و مستقل انجام دهید.
python3 design-system/build_android_v6598.py --app admin --apk design-staging/admin.apk --expected-sha 4d06d6e76f6e7238ea01b4759f617087c195741267f191d89e0a865aff3f1eea
(cd android-build && gradle --no-daemon -PzaviApp=admin :app:assembleRelease)
```
برای دو ویندوز x64 از PowerShell، نصب `gh`, Python, Node, npm, بسته‌بندی Electron و دسترسی GitHub لازم است:
```powershell
./windows-build/build-unified-design-v6598.ps1
```
