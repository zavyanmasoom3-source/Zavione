# ZAVI ONE ADMIN V1.0 — پنل مدیریت مرکزی

تاریخ بسته: ۲۳ اکتوبر ۲۰۲۶

## هدف
پنل مخصوص مالک اصلی ZAVI ONE بر پایه سورس قبلی ADMIN طراحی شده است. طراحی آبی/فیروزه‌ای تازه، لوگوی رسمی ارسالی شما، انیمیشن ورود، منوی موبایل، حالت روشن/تیره و داشبورد جدید اضافه شده‌اند. هدف از این نسخه **انتشار آزمایشی و آزمون عملیات واقعی** است، نه ادعای «بدون هیچ مشکل».

## فایل نشر
کل محتوای ZIP نسخه وب را مستقیماً در پوشهٔ Publish یک سایت جداگانه ADMIN قرار دهید. فایل `index.html` باید در ریشه باشد.

## بخش‌ها و وضعیت اتصال
| بخش | وضعیت |
|---|---|
| ورود مدیر | احراز هویت سرور و RPC موجود؛ نیازمند حساب مجاز |
| داشبورد | آمار واقعی از فهرست فروشگاه‌ها و اشتراک‌ها، بدون اعداد ساختگی |
| فروشگاه‌ها | جستجو، فیلتر، صدور CSV، تمدید و تعلیق اشتراک با تأیید سرور |
| سوابق تمدید/پرداخت | بر پایه توابع موجود سرور |
| حسابداری درآمد | بر پایه ماژول موجود و RPCهای گزارش |
| دستگاه‌ها | مسیر مستقیم به مدیریت برند، انتقال دستگاه و سیاست آفلاین با تأیید سرور |
| پشتیبانی و رسیدها | استفاده از خدمات موجود سرور |
| سلامت سیستم | بررسی زنده نشست و ارتباط با درخواست کاربر؛ بدون درصد uptime ساختگی |
| فعالیت‌ها | بر اساس تاریخ تمدیدهای موجود؛ *Audit کامل* نیست |
| امنیت و تنظیمات | دسترسی مالک، مدیریت نشست و تغییر رمز |
| نمای موبایل و تبلت | طراحی واکنش‌گرا و منوی دارای اسکرول؛ نیازمند آزمون روی دستگاه واقعی |
| انیمیشن ورود | نمایش کوتاه لوگو/عنوان و احترام به reduced-motion |

**نکته:** صفحه‌های تجمیعی جدید بر پایه RPCهای موجود ساخته شده‌اند. توسعهٔ جداگانه برای مدیریت کامل کارمندان تمام فروشگاه‌ها، آمار همه دستگاه‌ها، ممیزی سراسری و وضعیت زیرساخت در لحظه، به APIها/جداول مستقل و تست امنیتی نیاز دارد. این ویژگی‌ها به‌اشتباه «فعال» نمایش داده نمی‌شوند.

## امنیت بسیار مهم
- کلید `service_role` یا Secret Key را هرگز داخل سایت قرار ندهید. فقط کلید Publishable قابل استفاده است.
- در بررسی فقط-خواندنی سرور مرکزی، `private.zavi_is_billing_admin()` مجوز را بر اساس UID حساب در جدول خصوصی بررسی می‌کند و آن جدول فعلاً **یک** حساب مدیریتی دارد.
- نسخه جدید اجازه ورود مرورگری را به ایمیل مالک شناخته‌شده محدود کرده است؛ امنیت قطعی همچنان باید **در دیتابیس و همه RPCهای مدیریتی** کنترل شود، نه فقط JavaScript.
- حالت نمونه در دامنه‌های عمومی غیرفعال است؛ فقط روی localhost برای آزمایش رابط در دسترس خواهد بود.
- اطلاعات ورود در مرورگر مورد اعتماد طبق سازوکار نسخه قبلی حفظ می‌شود. روی دستگاه مشترک وارد ADMIN نشوید؛ بعد از کار Sign Out کنید و احراز هویت دومرحله‌ای را برای حساب فعال کنید.
- پنل ADMIN را در دامنه/ساب‌دامنه جدا (مثلاً `admin.YourDomain`) منتشر کنید و با حساب مشتری وارد آن نشوید.
- هیچ‌گونه تغییر یا حذف داده در دیتابیس واقعی انجام نشده است.

## راه نصب امن
1. پیش از جایگزینی ADMIN فعلی، از فایل نسخه قبلی و تنظیمات بک‌آپ بگیرید.
2. ZIP مربوط به وب را در یک سایت آزمایشی *جدا* منتشر کنید (نه روی دامنه فروشگاهی ZAVI ONE).
3. در مرورگر موبایل و کامپیوتر پنل ورود، انیمیشن، جابه‌جایی بخش‌ها، اسکرول منو و هر دو تم را بررسی کنید.
4. با حساب اصلی، خواندن فروشگاه‌ها و تیکت‌ها را تست کنید. **برای آزمون، پرداخت واقعی یا تغییر دستگاه مشتری را ثبت نکنید.** عملیات مالی باید با داده آزمایشی مجزا یا تأیید حسابداری انجام شوند.
5. بعد از تأیید دسترسی و آزمون واقعی، فایل را برای دامنه اصلی ADMIN استفاده کنید.
6. در صورت مشکل، به ZIP قبلی ADMIN بازگردید؛ حافظه مشتریان یا دیتابیس را پاک نکنید.

## آزمون این بسته
- آزمون ساختاری JavaScript: ۲۶ فایل، بدون خطای نحو.
- ۳۴ فایل CSS، بدون ناموازنی آکولادها.
- شش صفحه جدید با داده نمونه در Node.js رندر و بررسی شد.
- ۵۷ ارجاع محلی فایل در HTML: فایل گمشده ندارد.
- ساختار محدودیت نمایش نمونه و کنترل اولیه مالک بررسی شد.
- مرورگر خودکار محیط ساخت، دسترسی به صفحه محلی را با `ERR_BLOCKED_BY_ADMINISTRATOR` مسدود کرد. **آزمون واقعی UI در مرورگر هنوز تأیید نشده است.**
- سرور Supabase پروژه `wbbmwfnmurpphwxesssx` فقط برای خواندن تابع‌های مدیریتی و تعداد مجوزهای مالک بررسی شد؛ هیچ تغییر Schema یا داده صورت نگرفت.

## اصلی‌ترین فایل‌های جدید
- `z1-admin-official.jpg` و `icon.png`: لوگوی رسمی ارسال‌شده توسط مالک
- `zavi-admin-next-v1.css`: طراحی جدید و واکنش‌گرا
