# ZAVI ONE و ZAVI ONE ADMIN — وضعیت واقعی بازسازی و انتشار
تاریخ: ۳ نوامبر ۲۰۲۶

## منبع نسخه‌های فعلی
- شاخه مستقل `fix/independent-source-release-20261103` دو پوشه `app-source/one` و `app-source/admin` دارد.
- اصل سورس‌ها از آرشیو **وب** `ZAVI_ONE_V65_83_IPAD_WEB_PWA_QA.zip` و `admin-v145-responsive-web.zip.base64` بازیابی شده‌اند، نه از APK قدیمی V66.06.
- `app-source/RECOVERY_PROVENANCE.json` منشأ و SHA-256 فایل‌های بازیابی را حفظ می‌کند.
- هشدار: بازیابی از وب قدیمی به‌تنهایی اثبات نمی‌کند همه تغییرات موجود در APK جدیدتر V66.06 به سورس برگشته‌اند. باید با تست ویژگی به ویژگی تأیید شود.
- Workflow جدید `zavi-source-only-android.yml` برای ساخت APK از پوشه‌های سورس استفاده می‌کند. Workflow قدیمیِ وابسته به APK نباید مسیر انتشار اصلی باشد.

## تکمیل‌شده و بررسی‌شده
- خرید چندکشوری، ارزهای مختلف، تبدیل نرخ، مصارف ترانسپورت و گمرک، در سورس مستقل ثبت و در تست‌های مرورگر با داده جعلی بررسی شد.
- سه حالت Light، Dark و Glass و دروازه ورود مختصر، در تست مرورگر بررسی شد.
- `zavi-warehouses-v1.js` و CSS مرتبط برای فهرست/ایجاد/فعال-غیرفعال‌کردن گدام‌ها از `public.zavi_warehouses` استفاده می‌کنند. این بخش با JWT مالک و RLS سرور محافظت شده است و صرفاً فهرست localStorage نیست.
- آزمایش `tests/warehouse-browser.cjs`: GET، POST، PATCH، انکار viewer؛ در GitHub Actions روی Chromium با API شبیه‌سازی‌شده موفق.
- دو APK **Debug QA** جدید از سورس ساخته و امضای Debug آن‌ها در CI تأیید شده؛ بدون اعتبار انتشار عمومی.

## دیتابیس
- پروژه اصلی: `wbbmwfnmurpphwxesssx`. دو جدول `zavi_warehouses` و `zavi_warehouse_movements` با RLS مالک، و نمای `zavi_warehouse_stock_summary` وجود دارند.
- در بررسی امروز تعداد ردیف‌های گدام و حرکت موجودی هر دو صفر بود. هیچ داده مشتری تغییر نکرد.
- `database/staged/20261103_zavi_warehouse_no_negative_guard.sql` به‌عنوان Migration **پیشنهادی و اجرا نشده** با کد rollback ثبت شد. پیش از اجرا نیاز به بک‌آپ قابل بازیابی، کلون آزمایشی و تست همزمانی/RLS دارد.

## امضای APK
- در نسخه مستقل فقط به‌شکل QA ساخته شد: ZAVI ONE `66.63-source-qa` و ADMIN `1.4.54-source-qa`.
- نام‌های قدیمی GitHub Secrets برای هر دو برنامه موجودند، اما موجود بودن رمزها اثبات باز شدن keystore یا تطابق با APK نصب‌شده نیست.
- Workflow `zavi-source-signed-compatibility.yml` برای بازکردن کلید اصلی، ساخت مستقل امضاشده و بررسی package/certificate/versionCode نسبت به آرشیو V66.06 اضافه شد.
- تا زمانی که این بررسی موفق نشده، APK امضاشده را آپدیت بدون خطر اعلام نکنید؛ حتی پس از موفقیت آن، تست واقعی نصب و حفظ داده لازم است.

## موارد هنوز حل‌نشده / قابل ادعا نیست
۱. گدام چندگانه کامل: مقدار موجودی بر اساس گدام، انتقال اتمیک، کاهش هنگام فروش، افزایش هنگام خرید، همگام‌سازی آفلاین و جلوگیری از موجودی منفی در سرور **هنوز کامل نشده**.
۲. تست واقعی بک‌آپ و برگشت دیتابیس و آزمایش روی مشتریان آزمایشی انجام نشده.
۳. تمام صفحات سه‌زبانه، حالت Glass، دوربین Android/iPad، بارکد آفلاین، چاپ و واتساپ به‌صورت سرتاسری تأیید نشده‌اند.
۴. فرمان‌های دستیار، انتقال دستگاه، مجوز آفلاین و تمدیدهای ۷، ۱۸۰ و ۳۶۵روزه تست انتهابه‌انتها ندارند.
۵. امنیت ۸۳ تابع SECURITY DEFINER دسترس‌پذیر به authenticated نیازمند بازبینی دقیق کنترل‌های داخلی است؛ این هشدار به معنی نفوذ اثبات‌شده نیست.
۶. تست ارتقا با همان certificate روی دستگاهی دارای داده واقعی و QA میدانی انجام نشده است.
۷. انتشار عمومی و ادعای ۱۰۰٪ آماده بودن، در این مرحله ممنوع است.

## اصلاحات تکمیلی همین جلسه — ۳ نوامبر ۲۰۲۶
- مدیریت گدام اکنون علاوه بر ثبت نام و کود، موجودی هر گدام را از نمای RLSدار zavi_warehouse_stock_summary می‌خواند و جدا نمایش می‌دهد. ورود اطلاعات یک tenant دیگر در رابط فیلتر می‌شود؛ بیش از ۲۰۰ سطر فقط با هشدار نمایش داده می‌شود.
- تست Playwright ثبت و غیرفعال‌سازی گدام، انکار viewer، دقت موجودی و فیلتر tenant را بررسی کرده است. تمام داده‌ها ساختگی‌اند.
- اسکن بارکد به بسته کاملاً محلی ZXing مجهز شد؛ نبود BarcodeDetector در iPad باعث غیرفعال‌شدن اسکن نمی‌شود. راه‌اندازی دوربین پس از کلیک است و جریان دوربین بعد از تشخیص یا بستن قطع می‌شود. آزمون Chromium با دوربین شبیه‌سازی‌شده پاس شده؛ تست روی iPad و Android واقعی هنوز لازم است.
- دو Migration اجرا نشده در database/staged برای محافظ موجودی منفی، حذف امتیاز TRUNCATE و ثبت تکرارناپذیر حرکت گدام آماده شده است. تست PostgreSQL 17 روی داده ساختگی برای موجودی منفی، دسترسی مالک، idempotency و دو برداشت همزمان پاس شده؛ هیچ Migration روی دیتابیس مشتریان اجرا نشده.
- دو APK سورس-only جدید، با شماره ZAVI ONE 66.64-source-qa و ADMIN 1.4.55-source-qa ساخته شدند؛ این دو فقط Debug QA هستند.
- آزمون ارتقای نصب قبلی به دلیل تفاوت شناسه package و certificate همچنان fail می‌شود. روی برنامه دارای داده مشتری جایگزین نشوند.
- دستیار آفلاین صوتی، همگام‌سازی کامل موجودی با خریدوفروش، آزمون روی iPad واقعی، WhatsApp، سه زبان کامل، مجوز و انتقال دستگاه و تست نسخه قابل انتشار هنوز تأیید نشده‌اند.
