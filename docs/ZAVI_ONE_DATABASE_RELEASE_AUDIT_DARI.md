# ZAVI ONE — دیتابیس اصلی و آمادگی انتشار
نسخه بررسی: ۲۷ اکتوبر ۲۰۲۶، پروژه اصلی Supabase wbbmwfnmurpphwxesssx

## وضعیت تأییدشده
دیتابیس اصلی فعال است و در schema عمومی ۲۲ جدول فعلی دارد: اشتراک، ورک‌اسپیس، دستگاه‌ها، عملیات همگام‌سازی، اجازه همکاران، پروفایل صنف، خدمات، دسته‌های داروخانه، تراکنش اشتراک و رویدادهای مجوز.
توابع مدیریت مرکزی، تمدید هفت‌روزه، دستگاه‌ها و مجوز آفلاین وجود دارند.
این نسخه‌ی رابط کاربری هیچ جدول/مجوز/اشتراک مشتری را در دیتابیس فعال تغییر نمی‌دهد.

## موارد حیاتی پیش از انتشار تجاری
۱. ۸۳ تابع SECURITY DEFINER در public برای کاربران authenticated قابل فراخوانی‌اند؛ این هشدار به معنی نفوذ اثبات‌شده نیست اما مجوز اجرای هر تابع و کنترل server-side مالک باید بازبینی شود.
۲. ۱۷ جدول با RLS و بدون policy وجود دارند؛ ممکن است عمدی باشند (فقط از طریق RPC امن)، لذا به‌صورت کورکورانه policy عمومی ایجاد نکنید.
۳. با حساب فروشگاه یا همکار، دسترسی به توابع ADMIN باید در پایگاه‌داده رد شود؛ UI مخفی به تنهایی امنیت نیست.
۴. تست RLS بین دو فروشگاه و سناریوی کار آفلاین/همگام‌سازی بی‌ضرر در محیط staging.
۵. نسخه پشتیبان قابل بازیابی و تمرین بازیابی، کنترل مهاجرت‌ها، ارزیابی log، indexes و خطرات.
۶. هیچ کلید service_role در فایل‌های APK/ZIP/EXE و مرورگر قرار نگیرد.
۷. نصب نسخه اصلی APK با کلید امضای release پایدار و تست انتقال داده از نسخه فعلی.

## تصمیم
به دلیل وجود اطلاعات واقعی مشتریان و ریسک امنیتی، مهاجرت DDL یا پاک‌کردن داده انجام نشد. پایگاه داده مجزا یا کپیِ «کامل و آماده انتشار» بدون آزمایش RLS، migration و backup واقعی نمی‌تواند تأیید شود.
