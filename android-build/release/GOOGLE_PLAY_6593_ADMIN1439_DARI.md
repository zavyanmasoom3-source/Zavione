# انتشار آزمایشی Google Play — ZAVI ONE 65.93 و ADMIN 1.4.39

این بسته یک **AAB با شناسه اصلی** آماده می‌کند؛ در صورت نبود کلید مالک، فایل با نام **UNSIGNED_REQUIRES_OWNER_KEY** منتشر می‌شود و **قابل آپلود در Google Play نیست**.

- شناسه‌ها: `com.zavione.one` و `com.zavione.one.admin`
- `versionCode` در این آزمایش: 6593 و 4390. در Play Console باید از بزرگ‌تر بودنشان نسبت به نسخه ثبت‌شده مطمئن شوید.
- سطح هدف: **Android API 36** مطابق الزامات ۳۱ اگست ۲۰۲۶.
- فایل امضای آپلود و رمزها را در متن گفتگو، کد، فایل ZIP یا GitHub Release نگذارید. فقط از Secretهای GitHub با نام‌های نوشته‌شده در `android-build/release/GOOGLE_PLAY_RELEASE_GUIDE_DARI.md` استفاده کنید.
- AAB با کلید QA/Debug امضا نشود. گزارش جداگانه مشخص می‌کند `SIGNED_UPLOAD_CANDIDATE` است یا `UNSIGNED`.
- آماده‌سازی فنی فایل، تأیید یا نشر در Play Store نیست. Privacy Policy، Data safety، حذف حساب، احراز هویت مالک، اجازه دوربین، محتوای مالی، فرم App access و تست داخلی باید تکمیل شوند.
- پنل ADMIN فقط مالک مرکزی را مجاز می‌داند. برای یک نفر، انتشار خصوصی ممکن است مناسب‌تر از انتشار عمومی باشد.
- دربارۀ پیام تمدید: پیام واتساپ فقط با اقدام مدیر باز می‌شود. عکس داخل مرورگر ساخته می‌شود؛ ارسال قطعی و انتخاب مخاطب از طرف مدیر صورت می‌گیرد.
- نسخه قبلی آفلاین را بدون پشتیبان حذف نکنید. امضای Play با APK آزمایشی سابق ممکن است متفاوت باشد.
