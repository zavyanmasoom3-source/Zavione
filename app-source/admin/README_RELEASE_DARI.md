# ZAVI ONE ADMIN V1.1 — راهنمای انتشار (دری)

- لایه یکپارچه حالت روشن/تیره برای داشبورد، منوی مرکزی، جدول‌ها، فورم‌ها، پنجره‌ها، بخش‌های مالی و صفحه ورود اضافه شده است.
- دکمه تغییر سریع رنگ با آیکون ماه/خورشید در بالای پنل اضافه شده است. انتخاب در دستگاه ذخیره می‌شود.
- لوگوی رسمی Z1 ADMIN و انیمیشن ورود نسخه V1.0 حفظ شده است.
- نمایش آماری فقط بر اساس فهرست‌های دریافتی از سرور است؛ عدد دستگاه‌ها و درصد پایداری ساختگی ساخته نمی‌شود.
- ماژول‌های فروشگاه، اشتراک، دستگاه، تیکت، تمدید، درآمد، فعالیت‌ها، سلامت، مدیریت برند، امنیت و تنظیمات از کد اصلی حفظ شده‌اند. مجوز عملیات حساس را سرور کنترل می‌کند.
- فایل CSS و JS جدید در کش انتشار با نسخه تازه ثبت شده‌اند.
- این بسته را در سایت جداگانه ADMIN و روی دامنه ثابت آزمایشی نشر کنید؛ آن را با ZIP فروشگاهی روی یک سایت ترکیب نکنید.
- کلید عمومی قابل استفاده است؛ هرگز secret/service_role یا رمز دیتابیس را در مرورگر قرار ندهید.
- ورود واقعی مالک، تمدید اشتراک آزمایشی، سوابق پرداخت و انتقال دستگاه باید در محیط واقعی و با مجوز معتبر تست شوند.
- دسترسی تنها مالک باید از سمت سرور تأیید شود؛ ظاهر منو جایگزین کنترل دسترسی نیست.

وضعیت: بررسی نحوی، شش رندر اختصاصی و آزمون تغییر رنگ در مرورگر آزمایشیِ مستقل موفق. مرورگر محیط اجازه بازکردن سایت محلی را نداد و آزمایش کامل محیط واقعی انجام نشده است.
